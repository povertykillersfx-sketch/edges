# Edges EA Control (mobile)

Expo (React Native) UI for starting, stopping, and removing a mocked Edges EA session. Visual-only — no broker, tradeport, or live trading logic.

## Run

```bash
cd mobile
npm install
npx expo start
```

Press `w` for web, or scan the QR code with Expo Go on a device.

## Controls

- **Quotes** — mock alert (no market data)
- **Start / Stop** — toggles local running/stopped state
- **Remove** — clears the session to a removed status
